# CRUD-OPERATIONS-Shell
A Shell scripting project demonstrating CRUD (Create, Read, Update, Delete) operations using a command-line interface.

## About the Project

The purpose of this project was to practice using Shell commands and scripting to manage data through the command line. The project demonstrates how users can create, view, update, and delete records.

## CRUD Operations

### 1. Create
The Create operation allows the user to add a new record to the system.
